# Michal Geyer

Personal website: https://michal-geyer.github.io/

A static website containing research, news, contemporary dance, and contact links.

## Editing

- `index.html`: page content and links
- `styles.css`: layout and colors
- `script.js`: section controls and video playback behavior
- `assets/`: images, research demonstrations, and favicon

## Publishing

GitHub Pages serves the root of the `main` branch. No build step is required.
